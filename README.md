# lm-dotfiles

This folder contains the dotfiles for my Linux Mint setup. It also contains a few install scripts so that if/when I do a fresh install on another PC, I can quickly get everything up and running.

I use Linux Mint mostly for software development, but it also includes a Steam install so I can play my PBEM turns while I'm working (I have a separate PC running Windows for gaming).

## Installed software
### Apps
* VS Code
* Steam
* Claude
* Codex
* Slack
* 1 Password
* WezTerm
* Docker

### Command line tools
* Neovim
* Starship Prompt
* fd (find replacement)
* ripgrep (grep replacement)
* eza (ls replacement)
* bat (cat replacement)
* lazygit
* lazydocker
